# Вариант B — запуск и тест

Сделано (Часть 1): синхронизация **всех ячеек** между шефом и Аскаром + авторская подсветка + ручной сброс цвета. Структура (добавление разделов/пунктов) — Часть 2, следующим заходом.

## Что изменилось в коде

- `index.local.html` — синк всех ячеек (коллекция `cells`), цвет правок, кнопка «Отметить просмотренным».
- `deploy.sh` — публичная версия теперь = копия мастера (без заморозки; роль определяется по hostname).
- `firestore.rules` — два набора правил (временный для теста / боевой).

## Модель цвета

- Правки **шефа** → 🔴 красный фон (видит Аскар).
- Правки **Аскара** → 🟢 зелёный фон (видит шеф).
- Свои правки себе не подсвечиваются.
- Кнопка **«Отметить просмотренным»** гасит цвета правок другой стороны (для нажавшего).

## Тест функциональности (5 минут, делается ДО закрытия доступа)

1. **Открыть доступ к Firestore на время теста:**
   Console → Firestore → Rules → вставить **НАБОР 1** из `firestore.rules` → Publish.
2. **Открыть мастер локально** (роль = Аскар): `open index.local.html` в браузере, ввести PIN `1303`.
3. **Открыть боевой** (роль = Шеф) во второй вкладке: https://askar1992.github.io/status-dashboard/ — PIN `1303`.
   *(Примечание: на боевом ещё старый код — для теста синка двух ролей можно вместо этого открыть `index.local.html` через локальный сервер на 127.0.0.1, тогда роль = Аскар. Полноценную проверку «шеф vs Аскар» делаем после деплоя Части 1 — см. ниже.)*
4. Изменить ячейку в одной вкладке → во второй она обновляется и подсвечивается цветом автора.
5. Нажать «Отметить просмотренным» → цвет гаснет.

## Деплой Части 1 на боевой (после успешного теста)

```
./deploy.sh
```
Запушит новый код в публичную версию. После этого шеф сможет редактировать все ячейки онлайн.

## Закрытие доступа (Часть 1.5 — обязательно, делаем вместе)

Сейчас Firestore открыт всем (НАБОР 1). Чтобы запереть:
1. Console → Authentication → Sign-in method → **Anonymous** → Enable.
2. Я добавлю в `index.html` анонимный вход (`signInAnonymously`).
3. Console → Firestore → Rules → переключить на **НАБОР 2** → Publish.
4. (Опц.) Ограничить API-ключ по домену — см. `Status_Dashboard.md`, раздел про Secret Scanning.

## Round-trip (правки Аскара через мастер)

Перед тем как Аскар правит мастер: открыть боевой онлайн (там правки шефа), нажать «Экспорт изменений (JSON)» → передать мне → применяю в мастер → деплой. Так правки шефа не теряются.
